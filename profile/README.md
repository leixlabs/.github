# Lei Studio

独立开发者的产品与工具。能跑在自己机器上的，就不依赖云端。
*Local-first products and tools by one developer.*

## 项目

- **[MonoSub](https://github.com/leixlabs/monosub)** · Rust — 视频/音频转文字，全程本地。已上架 Microsoft Store。
- **[Hangar](https://github.com/leixlabs/hangar)** · Rust — Clash 订阅管理 CLI，含配置服务器、文件监控、AI 改配置。
- **[Paperplane](https://github.com/leixlabs/paperplane)** · JavaScript — Chrome 内置 AI 本地摘要网页，直发 Telegram。MV3，零后端。
- **[食刻 / Calory](https://github.com/leixlabs/kcalapp)** · Dart — 拍餐食照片，多模态 LLM 出热量与营养素。
- **[Selected AI](https://github.com/leixlabs/selected-ai)** · Swift — macOS 划词 AI 工具条。
- **[Synapse](https://github.com/leixlabs/synapse)** · Extension + Server — 多平台内容同步进 Notion。
