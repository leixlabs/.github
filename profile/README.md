# Lei Studio

独立开发者的产品与工具。能跑在自己机器上的，就不依赖云端。
*Local-first products and tools by one developer.*

## Featured Work

三件我自己最满意的作品。顺序固定，与 [leix.dev](https://leix.dev) 和 [leixlabs.com](https://leixlabs.com) 保持一致。

### 01 · [MonoSub](https://monosub.leix.dev/)

把视频与音频转成字幕，全程在你自己的电脑上完成。
*Turns your videos and audio into subtitles — locally, on your own machine.*

Rust 桌面应用 · Windows / macOS · 本地转写 + 字幕翻译 · 已上架 Microsoft Store

### 02 · [食刻 Calory](https://github.com/leixlabs/kcalapp)

拍一张照片，记下这餐的热量与营养。数据只留在你的手机里。
*Snap a photo of a meal and get its calories and macros. Data stays on your phone.*

Flutter / Dart · iOS 已上架 App Store · 自带多模态 LLM 识别食材

### 03 · [Synapse](https://updates.leix.dev/about/)

把散落在各个平台的收藏，收进你自己的一个文件夹。
*Collects what you save across platforms into one folder you actually own.*

Go + Chrome MV3 · 十个平台写成本地 Markdown · 静态站点只做阅读器
